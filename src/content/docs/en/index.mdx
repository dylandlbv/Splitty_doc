## Why Splitty?

<CardGrid stagger>
	<Card title="Multi-household" icon="seti:folder">
		Each household has its members, incomes and expenses. The household creator is an admin and invites other members by email.
	</Card>
	<Card title="Flexible splitting" icon="random">
		Common expenses are split equally, or proportionally to each member's declared income for the month.
	</Card>
	<Card title="Optimized repayments" icon="approve-check">
		For each month, Splitty computes everyone's balance and suggests transfers (greedy method) that minimize the number of payments.
	</Card>
	<Card title="No rounding errors" icon="seti:db">
		All amounts are stored in cents (bigint): no floating-point arithmetic anywhere.
	</Card>
</CardGrid>
